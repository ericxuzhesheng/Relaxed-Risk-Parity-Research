# 周频约束实验

约束实验用于解释七个正式模型中的配置差异，不新增模型名称。主模型和六个对照的定位见 README。

## 运行

设置 `TUSHARE_TOKEN` 后运行。新实验先刷新行情与利率，已有结果仅在配置和输入一致时复用。

```powershell
python scripts/run_weekly_constraint_research.py
python scripts/run_weekly_constraint_research.py --risk-free-zero
```

已有目录需加 `--resume`。原研究目录使用滞后中债利率，零利率结果写入 `results/weekly_constraint_research_rf0/`。

## 数据与时序

实验保留复权价格的真实极端收益，上市前不回填。旧收益过滤口径只用于归档复现。每次优化使用调仓日前数据，权重按项目日频约定记账并扣除 3 bps 单边成本。

## 实验设置

固定实验包括月度和周频集中度约束对照，以及取消现金上限、取消单资产上限、同时取消两项上限和取消换手硬上限。风险估计实验使用协方差收缩、相对 CVaR 约束及二者组合。

仅取消现金上限仍保留单资产上限。相对 CVaR 以同目标下的基准组合为上限，因此基准仍然可行且最优。微小数值差异不作为收益改善证据。

## 输出

每项实验保存日收益、权重、交易和求解诊断。约束表记录实际值、松弛量、对偶变量与触及状态，容差沿用求解器的 `5e-5`。失败记录和运行日志保留。

汇总包含净绩效、换手、成本及集中度，另列自然年结果和相对周频对照的配对差异。`target_met` 只表示历史净夏普达到 1.0。现金权重和无风险利率须与该标记一并解释。

主模型在研究后由用户指定，实验入口不自动替换正式模型。当前发布结果以 `results/tables/` 中的主模型表为准。
