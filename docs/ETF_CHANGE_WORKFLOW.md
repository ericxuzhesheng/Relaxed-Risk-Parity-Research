# ETF 资产池维护

资产定义统一保存在 `src/asset_universe.py`。正式池与候选池分开，候选资产不参与回测。每只资产累计达到 60 个有效历史观察后才可进入组合，上市前数据不回填。

## 调整前

核对官方名称、代码、资产类别和有效行情。说明调整能增加哪类风险来源，结合流动性与共同样本相关性评估，避免按全样本收益挑选资产。资产池调整须明确授权，不随文字更新或例行回测自动执行。

## 执行顺序

1. 修改资产定义，确认正式池与候选池没有交集。
2. 设置 `TUSHARE_TOKEN`，按授权的数据区间刷新行情与利率。
3. 运行 `scripts/run_primary_publication_pipeline.py`，检查共同日期、权重和交易成本。
4. 核对生成的资产表、数字和图表，更新 README、AGENTS、论文与答辩稿。
5. 编译并检查两个 PDF。得到提交或推送授权后，再发布相关文件。

```powershell
python scripts/run_primary_publication_pipeline.py
```

主模型规格和历史研究输入有一致性检查。资产池确需改变时，应建立独立结果目录并重新运行所需对照，不能绕过检查复用旧实验。

## 模型与材料

正式文稿仅列 README 中的七个模型。资产池、参数和频率实验不另命名为模型。说明材料只写当前有效设置和结果，归档记录用于追溯。参考教材与临时文件不纳入发布。
