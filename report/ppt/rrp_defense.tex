\section{凸优化方法}
\begin{frame}{风险预算参考}
\[
\min_{x>0}\;\frac12x^\mathsf{T}\Sigma_t x-\sum_i b_i\log x_i,
\qquad q_t=\frac{x_t}{\mathbf1^\mathsf{T}x_t}.
\]
\begin{itemize}
\item 对全部当期合格资产设等风险预算
\item 240 个历史观察，采用 Ledoit--Wolf 收缩协方差
\item 收益估计采用 20 个交易日半衰期
\item 所有估计只使用调仓日前历史数据
\item 正半定二次项与负对数项构成凸目标
\end{itemize}
\end{frame}
\begin{frame}{Global RRP 的凸松弛}
\[
\min_w\;\|w-q_t\|_2^2+0.10\frac{w^\mathsf{T}\Sigma_t w}{v_t}
+1.9\left[\max\left(0,\frac{R_t-\mu_t^\mathsf{T}w}{s_t}\right)\right]^2
\]
\[
\mathbf1^\mathsf{T}w=1,\quad w\geq0,\quad v_t=e_t^\mathsf{T}\Sigma_t e_t.
\]
\begin{itemize}
\item $e_t$ 为当期合格资产的等权组合
\item $R_t=1.9\max(\overline{\mu}_t,0)$，沿用历史预测收益规则
\item 多头、无杠杆；不再叠加求解后的风险缩放
\end{itemize}
\end{frame}
\begin{frame}{为什么调整方差尺度}
\begin{columns}[T]
\begin{column}{0.47\textwidth}
\textcolor{holdingBlue}{\textbf{风险预算参考方差}}
\par\medskip
参考组合偏向低波动资产时，分母可能很小，使方差惩罚过重，配置进一步向现金集中。
\end{column}
\begin{column}{0.47\textwidth}
\textcolor{holdingRed}{\textbf{当期等权组合方差}}
\par\medskip
仍惩罚组合风险，尺度由同一历史协方差与合格资产确定；没有新增集中度百分比，也未增加杠杆。
\end{column}
\end{columns}
\end{frame}

\begin{frame}{实现检查与资产参与}
\begin{itemize}
\item 每期检查 DCP 凸性、求解状态、预算及非负约束
\item 信息截止时间严格早于调仓日
\item 使用交易前漂移权重计算换手与成本
\item 检查每只 ETF 的合格期数、持有期数与最大持仓
\item $5\times10^{-5}$ 为数值检查阈值，不是最低持仓约束
\end{itemize}
\end{frame}
\begin{frame}{研究边界}
\begin{itemize}
\item 规格选择利用历史结果，尚需新增数据检验
\item 均值和协方差估计存在误差
\item 固定成本未证明实际成交、容量与市场冲击
\item 未处理负债、资本占用及久期缺口
\item 资产曾被使用，不等于风险贡献充分分散
\end{itemize}
\end{frame}
\section{结论}
\begin{frame}{研究结论}
\begin{itemize}
\item Global RRP 采用凸优化生成周频、多头、无杠杆组合
\item 净年化收益 \globalNetReturn，夏普 \globalSharpe
\item 收缩协方差与较快收益估计共同参与配置
\item \primaryAssetsUsed{} 只 ETF 曾形成超过数值容差的持仓
\item 后续冻结规格，用新增数据检验稳定性
\end{itemize}
