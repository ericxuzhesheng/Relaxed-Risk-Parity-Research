\section{相关研究与方法定位}
\subsection{风险预算与方差控制}
Markowitz 以预期收益和协方差建立组合选择框架\cite{markowitz1959portfolio}。风险预算进一步从边际风险和风险贡献确定资产配置，Qian、Maillard 等及 Roncalli 对相关思想与性质作了系统讨论\cite{qian2005risk,maillard2010properties,roncalli2013introduction}。Spinu 将风险预算计算写为含负对数项的凸问题\cite{spinu2013algorithm}，本文以此构造第一阶段参考组合。

风险贡献均衡与组合总风险控制各有作用。Feng 与 Palomar 的 SCRIP 框架将风险集中程度与投资者偏好结合，并以包含组合方差的均值与方差函数作为偏好项\cite{feng2015scrip}。Ardia 等研究风险型组合的绩效权衡\cite{ardia2018beyond}；Gambeta 与 Kwon 将收益目标引入二阶锥风险平价模型，以风险平价参考收益的倍数设置目标\cite{gambeta2020risk}。因此，将收益信息纳入风险平价和采用凸优化表示均已有先例，本文不将其本身视为新的理论贡献。

Costa 与 Kwon 在广义风险平价中同时权衡收益与风险，并对风险分散程度设置限制，还考虑收益估计不确定性\cite{costa2020generalized}。这一路径直接处理风险贡献之间的关系。本文采用资本权重到风险预算参考的平方距离，获得较简单的严格凸二次规划，但不直接约束最终风险贡献的偏离上限。两种距离不可混同：权重接近参考时风险贡献的变化仍取决于协方差结构和组合方差，第三章给出条件性界限，第五章检验实际偏离。

国内研究同样关注风险预算与其他目标的结合。景奎构建整合 ESG 的双层风险预算模型，以预算参数联系下层投资权重\cite{jing2026esg}。本文固定等风险预算生成参考，再调整最终权重，属于顺序求解的两阶段配置。其理论性质及两阶段之间的关系在第三章展开。

\subsection{参考跟踪与预测收益短缺}
Bourgeron 等在资产配置中使用围绕参考组合的 Tikhonov 正则化，以平方范数控制权重偏离\cite{bourgeron2018robust}。本文的 $\|w-q_t\|_2^2$ 沿用这一形式，并将参考设为当期风险预算组合。王志强、赵庆将基准跟踪与目标收益结合，讨论基金配置的收益、风险及成本\cite{wang2015tracking}。该文主要考察相对基准的收益跟踪误差，本文则直接度量资本权重距离。

收益目标也有风险平价研究先例。Gambeta 与 Kwon 先计算风险平价组合，再以其预期收益的一定倍数设定目标\cite{gambeta2020risk}。本文取倍数为一，使目标由当期可行参考组合确定，并以惩罚允许最终组合出现一定预测收益短缺。

两者的调整方向也不同：原研究以高于参考的目标推动组合偏离风险平价，而本文在参考收益处设置软目标，由方差项推动离开参考、由短缺项限制预测收益损失。因此，本文所检验的是降低总风险时的收益代价，不是通过提高目标倍数寻求增强收益。目标可由参考达到并不意味着最终解必然达到该目标，也不意味着有限惩罚等价于硬收益约束。

平方短缺项的数学依据来自不等式的二次罚函数。Nocedal 与 Wright 对约束违反量取正部并平方\cite{nocedal2006numerical}；Boyd 等在组合优化中讨论将投资要求转化为软约束，其正部惩罚说明了这种建模思路在配置问题中的用途\cite{boyd2017multiperiod}。本文将两者结合，对低于目标的预测收益偏差施加平方惩罚，超过目标的部分不受该项惩罚。

Siegmann 与 Lucas 对基准财富以下的随机短缺采用二次惩罚\cite{siegmann2005discrete}。刘家和等将状态依赖、损失厌恶与鲁棒配置结合\cite{liu2018lossaverse}，王宗润、何瑭瑭研究动态参照点及下侧风险控制\cite{wang2021reference}。这些文献支持以参照目标区分有利和不利偏离的经济动机。其中，随机财富短缺的期望与本文预测均值的短缺并不相同，本文采用后者表达当期配置的收益要求。

由此，方差项、参考跟踪和平方短缺各有方法依据。本文将它们整合到同一凸目标中，具体组合的配置效果仍需由消融和扣费实证评价。

\subsection{估计误差与鲁棒组合研究}
Chopra 与 Ziemba 指出输入估计误差会影响组合选择\cite{chopra1993effect}，Laloux 等讨论了有限样本相关矩阵中的噪声\cite{laloux1999noise}。本文采用 Ledoit 与 Wolf 的协方差收缩方法改善矩阵估计\cite{ledoit2004well}，收益向量则使用指数加权均值。两类估计均依赖历史样本，其可靠性与优化问题的可解性需要分别评价。

梁锡坤等从均值与方差模型出发综述鲁棒投资组合研究\cite{liang2014robust}。安晓敏针对收益与协方差参数扰动建立基于“势”不确定集的鲁棒模型\cite{an2014robust}，为处理输入不确定性提供了国内研究实例。本文使用收缩估计和参考正则化稳定配置，尚未显式建立不确定集上的最坏情形问题，因此将这些研究作为估计风险与模型扩展的依据。

国内另一类研究以尾部风险为核心。康志林、李仲飞在 CVaR 鲁棒均值与 CVaR 模型中考虑均值估计风险，并研究对偶与光滑求解方法\cite{kang2017cvar}；刘家和等从安全准则出发，通过最大违反概率表达安全要求\cite{liu2016cvar}。本文采用方差作为优化中的风险项，CVaR 仅用于事后评价。其尾部统计依据 Rockafellar 与 Uryasev 的相关研究\cite{rockafellar2000optimization,rockafellar2002conditional}，不据此将回测表现归因于未设置的 CVaR 约束。

\subsection{求解与实证定位}
\label{sec:literature_empirical}
凸优化为给定输入下的求解与最优性检验提供方法基础\cite{boyd2004convex}。本文使用已有求解器完成计算，重点考察模型设定和实际配置效果。国内风险平价实践与低利率环境下的配置研究提供了应用背景\cite{htsc2024practice,htsc2025lowrate}。

比较模型包括 HRP、HERC 所代表的层次配置思路\cite{lopezdeprado2016building,raffinot2018hierarchical}，以及等权和固定股债预算。DeMiguel 等的样本外研究说明简单配置有必要作为估计驱动模型的对照\cite{demiguel2009optimal}；Jagannathan 与 Ma 则讨论了非负约束缓和估计误差的作用\cite{jagannathan2003risk}。本文对层次模型的具体实现范围在第四章及附录中说明。

融资约束与波动管理研究提示，绩效差异还可能来自风险承担规模\cite{frazzini2014betting,moreira2017volatility}，因此本文结合持仓和事前风险匹配解释结果。交易成本按固定费率计入净收益，实际市场冲击与容量问题仍需额外建模\cite{almgren2001optimal}。历史分析也受规格选择影响\cite{white2000reality,bailey2014probability,bailey2017pbo}，本文将结论限定于当前资产池及研究规格，以消融、成本和执行检验说明配置机制及其实施条件。

\subsection{近期研究与本文的选择}
风险预算的近期发展进一步关注估计与决策之间的联系。Uysal 等将风险预算优化嵌入神经网络，以端到端方式连接输入信息与配置目标\cite{uysal2024endtoend}。本文保留历史估计、参考求解和最终优化三个可分别检查的环节，便于解释各目标项的作用；相应代价是未联合学习收益估计与投资决策，不能据此声称消除了估计误差。

Paolella 等研究厚尾收益与动态相关性下的风险平价\cite{paolella2025riskparity}，提示固定的二阶矩估计并不足以概括所有风险状态。本文采用线性收缩并在事后报告尾部损失，未建立厚尾条件分布或动态相关模型。Ledoit 与 Wolf 的二次收缩研究提供了不同于既有线性目标的协方差估计路径\cite{ledoit2022quadratic}。本文保留等方差对角目标以维持研究规格，并通过同一持仓在样本矩阵和收缩矩阵下的风险份额比较，揭示低波动货币工具对估计目标的敏感性；该诊断不构成不同估计器的优劣检验。

融资条件也是文献结论的边界。Asness 等将风险平价与杠杆厌恶联系起来\cite{asness2012leverage}。本文采用无杠杆资本预算，因而低波动资产的风险规模受资本占用限制。研究重点是给定可交易ETF集合内的配置取舍，不能直接外推为机构使用融资和衍生品时的风险平价结论。这些研究共同界定了本文在估计、决策与融资条件上的适用范围。

由此形成三个可检验问题：资本参考跟踪能保留多少风险均衡特征；收益短缺惩罚能否改变方差压缩的实际收益代价；年度参数更新相对于冻结系数是否具有增量作用。对应证据分别为距离与风险贡献配对诊断、目标项消融以及冻结参数比较。本文不以通用凸优化性质替代经济证据，也未在相同数据上复现上述全部原始模型，因此不作优于既有宽松风险平价方法的判断。

实证条件也需要区分。Gambeta与Kwon以50只美国股票开展分析，使用周收益计算绩效，并将换手作为交易成本规模的间接度量\cite{gambeta2020risk}。本文研究境内上市多资产ETF，使用日收益核算周度调仓净值，以单边3个基点乘以实际买卖权重变化计费。本文的年度候选与筛选规则由自身历史区间确定，不沿用原研究的参数搜索结果。因此，文献比较用于说明设计选择，不能以跨市场、跨时期的绩效数值直接证明方法优势。
