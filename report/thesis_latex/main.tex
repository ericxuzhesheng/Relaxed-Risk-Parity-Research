\clearpage
\begin{abstract}
本文研究全球 ETF 配置中的风险预算、收益目标和风险惩罚尺度。Global RRP 为主模型，HRP Benchmark、HERC Benchmark、Equal Weight 和 60/40 Benchmark 为对照。资产池包含 \etfCount{} 只 ETF，评价区间为 \evalStartDate{} 至 \evalEndDate{}，按 \annualizationDays{} 个交易日年化，单边约定成本为 \txCostBps{} bps。

主模型通过凸对数风险预算问题构造参考权重，再求解包含参考跟踪、组合方差和预测收益短缺的凸问题。收益目标取当期可行参考组合的预测收益。模型采用 \lookbackDays{} 日窗口、Ledoit--Wolf 收缩协方差和半衰期为 20 个交易日的指数加权收益估计。方差及收益短缺惩罚每年根据生效日前两个连续历史区间更新，随后冻结一年。组合为周频、多头、无杠杆，并允许全部满足历史数据条件的资产参与优化。

主模型净年化收益为 \globalNetReturn，年化波动为 \globalVolatility，夏普为 \globalSharpe，最大回撤为 \globalMaxDD。有 \primaryAssetsUsed{} 只 ETF 在合格期间曾形成超过数值容差的持仓。十个年度的候选均缺乏显著区分，模型结果属于探索性证据。

\noindent\textbf{关键词 } 宽松风险平价；全球资产配置；凸优化；ETF；交易成本
\end{abstract}
\clearpage
\renewcommand{\abstractname}{Abstract}
\begin{abstract}
This thesis evaluates Global RRP against HRP Benchmark, HERC Benchmark, Equal Weight and 60/40 Benchmark in a common universe of \etfCount{} ETFs. The evaluation spans \evalStartDate{} to \evalEndDate{}, uses \annualizationDays-day annualization, and deducts an assumed \txCostBps{}-bp one-way transaction cost.

Global RRP uses a convex risk-budget reference followed by a convex objective for reference tracking, portfolio variance and expected-return shortfall. The feasible return target equals the predicted return of the contemporaneous reference portfolio. The model uses a \lookbackDays-day window, Ledoit--Wolf covariance shrinkage and exponentially weighted return estimates with a 20-trading-day half-life. Penalties update annually from two strictly earlier historical blocks and remain fixed during the following year. The primary portfolio is weekly, long-only and unlevered.

The primary model records \globalNetReturn{} net annual return, \globalVolatility{} annual volatility, \globalSharpe{} Sharpe and \globalMaxDD{} maximum drawdown. A total of \primaryAssetsUsed{} ETFs receive material allocations during eligible periods. All annual candidates fall within one Sharpe standard error, so the data do not identify unique penalties. Historical design choices prevent an untouched model-selection claim.
\end{abstract}
